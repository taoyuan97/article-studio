## 2. 目标

实现文章列表页与文章创作工作台的全部功能：列表与过滤、新建文章、完整历史对话、流式正文、版本历史、模型切换、运行控制（发送/停止/重试/互斥）。完成后文章线功能与 MVP 等价。

## 3. 行为基线（继承 MVP 已验收语义）

- 正文只读，修改只能通过对话提出。
- 一篇文章只对应一个持续对话线程；页面不创建或替换 thread ID。
- 只有收到 `article.completed`（版本事务提交成功）后才替换正式当前正文。
- 取消：丢弃全部临时助手内容与临时正文预览，保留用户指令，正文与版本列表不变。
- 失败：丢弃临时正文，显示失败卡片；重试不复制用户消息文本，旧失败记录保留。
- 同一文章同时只允许一个活动运行（后端互斥，前端 409 提示）。
- 模型切换只影响后续请求；运行中禁用。
- SSE 断线（刷新/关闭）后重进通过 workspace 恢复最终状态；运行仍活跃时显示运行中并允许停止或等待。

## 4. 范围

### 4.1 必须实现

**文章列表页（`/articles`）**

- TanStack Query 加载文章列表（`limit=100`），按更新时间倒序。
- AntD Table：标题、状态、摘要、版本数、模型、更新时间、操作（继续创作）。
- 标题前端关键词过滤：忽略大小写、去首尾空白、空关键词恢复全部；只匹配标题。
- "新建文章" mutation → 跳转 `/articles/{id}`。
- 加载/空态/错误态（404、网络不可达）。

**文章工作台（`/articles/:articleId`）**

- 专注模式双栏布局：左历史对话（消息流 + 输入区），右当前正文（标题 + Markdown + 版本面板）。
- workspace 聚合接口一次加载全部初始数据（元数据、完整历史、当前正文、版本列表、可用/不可用模型、活动运行）。
- `MessageList`：消息分型样式（用户/普通回复/追问/无关引导/生成/修改/失败）；失败卡片（简短错误 + 可展开脱敏详情 + 重新发送按钮）；详情按纯文本渲染。
- `MarkdownView` 接入正文渲染。
- 正文面板：流式期间 `article.delta` 临时预览；`article.completed` 替换正式正文并刷新版本列表；取消/失败恢复生成前正文。
- `VersionPanel`：版本号/模型/时间；查看历史版本（标记"历史版本，只读"）+ 返回当前版本；不提供恢复/删除/编辑。
- `ModelSelect`：展示/切换 provider+model；运行中禁用；未配置项禁用并显示原因（不显示密钥值）。
- 运行控制：发送（202 → 运行态，禁用发送与切换）、停止（取消 API + 丢弃临时内容）、失败重试（retry API）、409 互斥提示。
- 重新进入时 `active_run_id` 存在则自动连接 SSE 并展示运行中。
- 404 → 提示并提供返回列表入口；网络中断保留输入内容。
- `article.delta` 流式渲染不阻塞输入区。

### 4.2 不实现

- 文章删除、归档、标签、全文检索。
- 版本恢复、对比。
- 跨刷新继续显示仍在运行的 token 流（重进恢复最终状态即可，与 MVP 一致）。

## 5. 状态与数据流设计

```text
TanStack Query（服务端状态）                Zustand / 组件局部（运行态）
┌─────────────────────────┐              ┌──────────────────────────┐
│ ['workspace', articleId]│   事件触发    │ activeRunId              │
│ ['articles']            │ ───────────→ │ temporaryAssistantText   │
│ ['versions', articleId] │  invalidate  │ temporaryArticleText     │
└─────────────────────────┘              │ streamStatus             │
                                         └──────────────────────────┘
```

事件处理（与 MVP 一致）：

| 事件 | 处理 |
|---|---|
| `run.started` | 进入运行态，禁用发送/切换 |
| `assistant.delta` | 更新临时对话气泡 |
| `article.delta` | 更新正文临时预览 |
| `message.completed` | 临时消息转正式（失效 workspace/messages 查询） |
| `article.completed` | 替换当前正文，刷新版本列表 |
| `run.cancelled` | 丢弃全部临时内容，退出运行态 |
| `run.failed` | 丢弃临时正文，展示失败卡片与重试按钮 |
| `run.completed` | 退出运行态，关闭连接 |
