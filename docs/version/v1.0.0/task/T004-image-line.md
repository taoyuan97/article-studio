## 2. 目标

实现配图工作台与素材库页面：配图会话的持续对话、SSE 图片生成流、图片参数浮层、保存素材，以及素材列表与详情。完成后图片线功能与 MVP（T005–T007 已定义范围）等价。

## 3. 行为基线（继承 MVP 已验收语义）

- 配图会话为持续对话：用户 prompt → 生成图片 → 展示；重新进入恢复完整历史与当前图片。
- 发送 prompt 返回 202 + run，连接 SSE 展示进度/完成/失败。
- 运行中禁用输入与发送；取消后不产生图片资产。
- 图片参数（分辨率档位、尺寸比例）经后端换算后随生成指令发送并持久化。
- 失败显示简短错误与脱敏详情。
- 保存素材记录来源会话与消息。

## 4. 范围

### 4.1 必须实现

**配图工作台（`/image-sessions/:sessionId`）**

- 专注模式布局：左会话对话 + 输入区（含 provider 选择），右当前图片预览区；顶部返回素材列表。
- workspace 加载（会话元数据、历史消息、当前图片、可用 provider、活动运行）。
- 发送 prompt（202 + run）→ SSE：`image.progress` 进度展示、`image.completed` 展示图片、`image.failed` 失败卡片（脱敏详情）。
- 运行态控制：运行中禁用输入/发送；"停止"按钮（取消 API）；取消后不产生资产。
- "图片参数"浮层（AntD Popover）：分辨率档位、尺寸比例选择，随发送指令提交（`tier`、`ratio`）。
- provider 选择：展示可用 provider，运行中禁用。
- "保存素材"：调用 `POST /api/assets` 写入资产库，成功反馈。
- 历史恢复与活动运行自动重连（`active_run_id`）。
- 错误路径：404、网络中断、`IMAGE_PROVIDER_NOT_CONFIGURED` 提示。

**素材库页面（`/assets`）**

- 素材列表（`limit=100`）：缩略图、标题、来源信息、更新时间。
- 点击查看素材详情（`GET /api/assets/{id}`）。
- "新建配图"入口 → `POST /api/image-sessions` → 跳转配图工作台。
- 加载/空态/错误态。

### 4.2 不实现

- 素材删除、编辑、分组、检索。
- 图片编辑、多图生成、批量生成。
- 从文章工作台直接发起配图（仅通过素材库入口，与 MVP 一致）。

## 6. 状态与数据流设计

```text
TanStack Query                        运行态（Zustand / 组件局部）
┌───────────────────────────┐        ┌──────────────────────────┐
│ ['image-workspace', sid]  │ 事件   │ activeRunId              │
│ ['image-sessions']        │ ─────→ │ progress                 │
│ ['assets']                │ 失效   │ streamStatus             │
└───────────────────────────┘        └──────────────────────────┘
```

事件处理：

| 事件 | 处理 |
|---|---|
| `run.started` | 进入运行态，禁用输入/发送/provider 切换 |
| `image.progress` | 更新进度展示 |
| `image.completed` | 展示图片，失效 workspace |
| `image.failed` | 失败卡片（简短错误 + 脱敏详情） |
| `run.cancelled` | 退出运行态，不产生资产 |
| `run.completed` | 退出运行态，关闭连接 |

## 7. 测试

- 假 provider 或真实 provider（通义万相/即梦）端到端：新建会话 → 发送 prompt（含参数）→ 进度 → 完成 → 保存素材。
- 取消路径：发送后停止，无图片资产产生。
- 失败路径：模拟供应商错误，展示脱敏详情。
- 素材库：列表、详情、新建配图入口。
- 参数持久化：重新进入会话后参数浮层回显上次选择。
