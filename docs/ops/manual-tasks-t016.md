# T016 人工验收：文章版本原生导出

## 状态

- 已完成（2026-08-27）：用户确认当前 Chrome、当前 Edge 人工验收全部通过。
- 自动化已覆盖：普通下载降级、Markdown/TXT 内容、默认文件名、取消与写入异常的组件级行为。

## 前置条件

1. 启动 Article Studio，并准备一篇至少有两个正式版本的文章。
2. 分别使用当前稳定版 Chrome 和 Edge 打开文章工作台。

## 每个浏览器的验收步骤

1. 正文区查看当前版本，点击“导出”：确认按钮位于“发布到公众号”左侧，弹窗默认选中当前版本和 Markdown。
2. 点击“导出”：确认系统“另存为”窗口出现；选择一个测试目录、修改文件名并保存。
3. 打开 `.md` 文件：确认内容与该版本 `content_markdown` 原文一致，无 frontmatter 或额外版本信息。
4. 切换正文区到历史版本后重新打开弹窗：确认默认选中该历史版本。
5. 选择 TXT 并导出：确认默认名为“版本标题-v版本号.txt”；打开后标题、列表、链接等 Markdown 标记已移除，正文和代码内容仍可读。
6. 再次导出并在系统窗口点击取消：确认页面不显示成功或失败提示，原文件未被覆盖。
7. 在文章生成过程中打开导出：确认只能选择并导出已完成的正式版本，不包含页面上的流式临时正文。
8. 打开一篇没有正式版本的文章：确认“导出”禁用，悬停提示“请先生成文章内容”。
