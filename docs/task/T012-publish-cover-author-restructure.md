## 2. 需求与现状

| 项 | 现状（T011 后） | 调整后 |
|---|---|---|
| 封面与作者 | 步骤 2「配图与位置」底部；封面从**已选配图**中 Radio 单选，勾选配图自动设第一张为封面 | 移至步骤 1；封面改为「选择封面」按钮 → **弹窗**展示图片网格并单选 |
| 步骤 1 标题 | 「选文章与版本」 | 「版本和信息」 |
| 步骤 2 | 缩略图墙 + 位置编排 + 封面/作者 | 只保留缩略图墙 + 已选图片位置编排 |

**可行性**：后端 `cover_asset_id` 为独立字段（与 `image_placements` 无关），ISSUE-001 已实证「仅封面无正文图」可成功发布。**纯前端改动，无后端变更。**

## 3. 已确认决策点（2026-08-24 与用户对齐）

| # | 决策 | 结论 |
|---|---|---|
| ① | 封面候选源 | **接受**封面可选不插入正文的图（微信草稿语义：封面是独立字段；同时解决纯文字文章无法发布问题——仅选封面即可发） |
| ② | 勾选配图时自动设封面 | **不自动设**：封面完全由步骤 1 决定；未选封面时发布链路自动用正文第一张图（wenyan 现有行为） |
| ③ | 切文章/版本时封面重置 | **切文章重置**（本文配图语境变化）；**切版本保留**（封面与版本内容无关） |
| ④ | 未选文章时「选择封面」可用性 | **可用**：弹窗仅显示「素材库图片」组；选文章后再打开会多出「本文配图」组 |
| ⑤ | 步骤 1 标题 | 改为「**版本和信息**」 |

## 4. 范围

### 4.1 必须实现

**PublishPage.tsx**

- `STEP_ITEMS[0].title` 改为「版本和信息」。
- 步骤 1 新增「封面与作者」区块：
  - 「选择封面」按钮 + 已选封面回显（缩略图、标题、清除按钮）；提示文案「不选封面时，发布将自动使用正文第一张图」。
  - 作者输入框（选填），行为不变（跨文章/版本保留，现状即如此）。
- 封面/作者状态（`coverAssetId` / `author`）保持页面级，仅渲染位置移动。
- `handleToggleAsset` 移除勾选时的 `setCoverAssetId(prev => prev ?? assetId)` 与取消时的封面回退逻辑（决策 ②）。
- 重置逻辑拆分（决策 ③）：
  - 切文章：清空已选配图、位置、封面、小节（现状行为，封面继续清）。
  - 切版本：清空已选配图、位置、小节；**保留封面**。
- 步骤 1 需要拿到分组候选（`articleAssets` / `libraryAssets`）传给封面弹窗（数据计算已在页面级，无需新增请求）。

**新组件 `features/publish/CoverPickerModal.tsx`**

- Props：`open`、`articleAssets`、`libraryAssets`、`selectedAssetId`、`onSelect`（确定）、`onCancel`。
- Modal 内图片网格单选：复用 `publish-picker-item` 样式与选中态；分组与步骤 2 一致（`articleAssets` 非空时「本文配图」置顶 +「素材库图片」全量，决策 ④）。
- 交互：点击图片即选中（单选，再点切换）；底部「确定 / 取消」；支持清除已选（回到未选封面态）。
- 素材库完全无图时空态引导（与步骤 2 缩略图墙一致）。

**ImagePlacementEditor.tsx**

- 移除「封面与作者」区块与相关 Props（`coverAssetId` / `author` / `onCoverChange` / `onAuthorChange`）。
- 「未选择图片也可以发布纯文字版本」文案微调（纯文字仍需步骤 1 选封面才可发布，提示指向封面区）。

**测试（Vitest，PublishPage.test.tsx）**

- 步骤 1 封面：打开弹窗 → 分组展示（选文章后含「本文配图」；未选文章仅「素材库图片」）→ 单选图片 → 确定后回显（缩略图 + 标题 + 清除）。
- 勾选配图不再自动设封面；未选封面时发布 payload `cover_asset_id` 为 `null`。
- 切版本保留封面、切文章重置封面。
- 作者输入在步骤 1 可用且随发布 payload 透传。
- 既有用例回归调整（封面默认第一张的断言改为显式经弹窗选择）。

**E2E（publish.spec.ts）**

- 主路径封面交互改为弹窗（打开 → 选封面 → 确定）；其余断言（组装 frontmatter `cover:` 字段、快照回显）不变。

**文档**

- README 使用指南「发布到公众号」一句同步（四步描述与封面弹窗）。
- 本任务文档状态与验收项同步。
