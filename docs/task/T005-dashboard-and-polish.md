## 2. 目标

实现首页仪表盘（统计、快捷入口、最近动态），并统一全站错误/加载/空态体验。完成后产品功能全部就位。

## 3. 范围

### 3.1 必须实现

**首页仪表盘（`/`）**

- 统计卡片（`GET /api/stats`）：文章总数、素材总数；卡片提供"查看全部"入口（跳转文章列表/素材库）。
- 快捷入口："新建文章"（`POST /api/articles` → 跳转文章工作台）、"新建配图"（`POST /api/image-sessions` → 跳转配图工作台）。
- 最近 5 篇文章：标题 + 相对更新时间，点击进入对应工作台。
- 最近 5 个素材：缩略图 + 相对更新时间。

**全局体验统一**

- `StatusBanner` 全局错误提示接入各页面（后端不可达、请求失败等），不打断已加载数据展示。
- 加载态统一（AntD Spin/Skeleton）：列表、工作台、仪表盘。
- 空态统一：文章列表空、素材库空、会话无历史、无版本等场景文案与样式一致。
- 相对时间格式化统一（`lib/format.ts`）。

### 3.2 不实现

- 图表类数据可视化。
- 全局通知中心、消息推送。
- 移动端适配。
