## 2. 产品概述

### 2.1 背景

MVP 原型已完成核心验证：

- DeepSeek 与 Kimi 双模型适配、统一 `ModelRegistry`，真实 API 冒烟通过；
- LangGraph 文章智能体：意图识别、追问、生成、全文修改、无关引导五种路由；
- 上下文预算（窗口 80%）、历史过滤、摘要与截断；
- Article / Conversation / Message / Version / Run 完整持久化，SSE 流、取消、失败脱敏、原消息重试、同文章运行互斥；
- 配图生成（通义万相、即梦）、配图会话、图片参数（分辨率档位、尺寸比例）、素材库；
- 原生 HTML/CSS/JS 前端完成端到端验收。

原型的前端为无构建的原生页面，仅用于验证产品假设，不具备工程化可维护性。本项目将 MVP 升级为正式项目：**功能等价迁移，前端技术栈升级为标准工程化方案**。

### 2.2 产品定位

单机（单用户、单进程部署）AI 文章创作工作台。用户通过自然语言对话完成文章的生成、修改与配图，系统自动维护文章版本与素材资产。

### 2.3 产品目标

1. **功能等价**：正式版覆盖 MVP 已验证的全部功能，行为语义不变（对话驱动修改、正文只读、版本不可变、取消丢弃临时内容等核心约束保持）。
2. **工程化**：前端升级为 React 19 + Vite + TypeScript 标准工程，具备类型安全、组件化、测试与构建能力。
3. **可部署**：生产环境单进程部署（FastAPI 托管前端构建产物），开发环境前后端分离热更新。
4. **可演进**：为后续登录权限、多人协作、RAG 等能力预留架构空间，但本期不实现。

### 2.4 成功指标

- MVP 全部端到端验收场景（列表、创建、对话续写、取消、失败重试、重启恢复、上下文压缩、配图、素材）在正式版复验通过；
- 前端通过 TypeScript 严格模式编译，核心组件具备测试覆盖，主路径具备 E2E 覆盖；
- 生产构建产物由后端单进程托管，`uvicorn` 一个命令即可启动完整应用。

## 3. 用户与使用场景

### 3.1 目标用户

个人内容创作者（单用户使用，无账号体系）。

### 3.2 核心场景

| 场景 | 描述 |
|---|---|
| 从零创作 | 新建文章 → 输入写作需求 → 智能体必要时追问 → 生成完整 Markdown 正文 |
| 迭代修改 | 在持续对话线程中提出修改要求 → 得到基于当前全文的新版本 → 查看历史版本 |
| 配图创作 | 从素材库新建配图会话 → 输入 prompt（可设分辨率/比例参数）→ 生成图片 → 保存为素材 |
| 素材管理 | 浏览素材库，查看已保存的图片资产 |
| 状态恢复 | 任意时刻刷新或重启，重新进入后恢复完整历史、当前正文与版本列表 |

## 4. 产品范围

### 4.1 功能全景

```text
Article Studio
├─ 仪表盘（首页）
│   ├─ 文章/素材统计
│   ├─ 快捷入口（新建文章、新建配图）
│   └─ 最近文章、最近素材
├─ 文章管理
│   ├─ 文章列表（最近 100 篇、标题前端过滤）
│   └─ 新建文章
├─ 文章创作工作台（专注模式）
│   ├─ 历史对话（持续线程、消息分型、失败详情与重试）
│   ├─ 当前正文（只读、流式预览、Markdown 安全渲染）
│   ├─ 版本历史（查看、只读、返回当前）
│   ├─ 模型切换（DeepSeek / Kimi，运行中禁用）
│   └─ 运行控制（发送、停止、重新发送、运行互斥）
├─ 配图工作台（专注模式）
│   ├─ 配图会话（持续对话、历史恢复）
│   ├─ 图片生成（SSE 进度、完成、失败、取消）
│   ├─ 图片参数（分辨率档位、尺寸比例）
│   └─ 保存素材
└─ 素材库
    └─ 素材列表（图片资产、来源信息）
```

### 4.2 页面与导航结构

| 页面 | 导航形态 | 路由 |
|---|---|---|
| 仪表盘 | 侧边导航壳 | `/` |
| 文章列表 | 侧边导航壳 | `/articles` |
| 素材库 | 侧边导航壳 | `/assets` |
| 文章创作工作台 | 专注模式（顶部返回列表） | `/articles/{articleId}` |
| 配图工作台 | 专注模式（顶部返回素材列表） | `/image-sessions/{sessionId}` |

侧边导航项：首页、文章、素材。工作台页面为专注模式，不带侧边栏，仅提供顶部返回链接（与 MVP 信息架构一致）。

## 5. 功能需求

各模块需求以 MVP 已验证行为为基线。行为语义与 MVP 不一致处，以本文档为准。

### 5.1 仪表盘

**FR-D1 统计卡片**

- 展示文章总数、素材总数（数据源 `GET /api/stats`）。
- 卡片提供"查看全部"入口，分别跳转文章列表、素材库。

**FR-D2 快捷入口**

- "新建文章"：调用创建 API 成功后跳转文章工作台。
- "新建配图"：调用创建配图会话 API 成功后跳转配图工作台。

**FR-D3 最近动态**

- 展示最近 5 篇文章（标题 + 相对更新时间），点击进入对应工作台。
- 展示最近 5 个素材（缩略图 + 相对更新时间）。

### 5.2 文章列表

**FR-A1 列表展示**

- 加载后端最近更新的 100 篇文章，按更新时间倒序。
- 行展示：标题、状态（是否已生成正文）、摘要（首条需求）、版本数、模型、更新时间。
- 未生成正文的文章同样展示。
- 不提供删除、归档或批量操作。

**FR-A2 标题过滤**

- 输入关键词仅对已加载文章的标题做前端过滤（忽略大小写、去首尾空白、空关键词恢复全部）。
- 不匹配正文、对话或摘要；不请求后端检索。

**FR-A3 新建与进入**

- "新建文章"调用 `POST /api/articles` 后跳转 `/articles/{id}`，初始标题"未命名文章"。
- 点击行或"继续创作"进入对应文章工作台。

### 5.3 文章创作工作台

进入页面加载 workspace 聚合接口（`GET /api/articles/{id}/workspace`），包含：文章元数据、完整历史对话、当前正文、版本列表、当前 provider/model、可用/不可用模型、活动运行状态。

**FR-W1 历史对话**

- 消息按 `sequence_number` 稳定排序，重新进入显示全部历史。
- 在原持续线程上继续对话；页面不创建或替换 thread ID。
- 消息按类型区分样式：用户消息、普通回复、追问、无关引导、生成结果、修改结果、失败记录。
- 失败记录显示简短错误 + 可展开的脱敏供应商详情 + "重新发送"按钮。
- 供应商详情按纯文本渲染，不执行 HTML。

**FR-W2 正文与版本**

- 当前正文只读，修改只能通过对话提出。
- 流式生成期间正文区实时预览增量；收到 `article.completed` 后才替换正式正文。
- 取消或失败时恢复生成前的正文。
- 版本列表展示版本号、模型、时间；点击查看完整正文并标记"历史版本，只读"。
- 提供"返回当前版本"；不提供恢复、删除、编辑历史版本或从历史版本继续修改。

**FR-W3 Markdown 安全渲染**

- 正文使用安全模式 Markdown 渲染（成熟库 + 白名单），禁用原始 HTML。
- 错误详情、标题、消息等动态内容默认转义。

**FR-W4 模型切换**

- 默认显示文章保存的 provider/model，新文章默认 DeepSeek。
- 模型 ID 由后端配置提供，前端不写死。
- 切换只影响后续请求；历史版本继续展示实际生成模型。
- 运行中禁用切换；未配置的供应商隐藏或禁用并显示原因（不显示密钥值）。

**FR-W5 运行控制**

- 发送消息后进入运行状态：禁用发送与模型切换，显示"停止"按钮。
- 停止：调用取消 API；立即丢弃临时助手气泡与临时正文预览；保留用户指令；当前正文与版本列表不变。
- 失败：丢弃临时正文，显示失败卡片与重试按钮。
- 重新发送：调用 retry API，不复制创建第二条用户消息，创建新运行，旧失败记录保留。
- 同一文章同时只允许一个活动运行（后端互斥，前端收到 409 时提示等待或停止）。

**FR-W6 SSE 断线恢复**

- 页面刷新或浏览器关闭导致 SSE 断开时，重新进入页面通过 workspace 接口恢复最终状态。
- 若运行仍活跃，页面显示运行中并允许停止或重新加载等待完成。

### 5.4 配图工作台

进入页面加载 `GET /api/image-sessions/{id}/workspace`（会话元数据、历史消息、当前图片、可用 provider、活动运行）。

**FR-I1 配图会话**

- 从素材库"新建配图"创建会话（可关联 article_id）。
- 会话内持续对话：用户 prompt → 生成图片 → 展示结果。
- 重新进入恢复完整历史与当前图片。

**FR-I2 图片生成与控制**

- 发送 prompt（202 + run）后连接 SSE，展示进度、完成、失败状态。
- 运行中禁用输入与发送，显示"停止"；取消后不产生图片资产。
- 失败显示简短错误与脱敏详情。

**FR-I3 图片参数**

- 提供"图片参数"按钮与浮层：分辨率档位、尺寸比例。
- 参数经后端换算后随生成指令发送，并持久化于会话。

**FR-I4 保存素材**

- 对当前图片提供"保存素材"：写入资产库（记录来源会话与消息）。

### 5.5 素材库

**FR-S1 素材列表**

- 展示最近 100 个图片素材：缩略图、标题、来源、更新时间。
- 点击查看素材详情（`GET /api/assets/{id}`）。
- 不提供删除、编辑、分组或检索。

### 5.6 全局行为

**FR-G1 错误处理**

- 404（文章/会话不存在）：提示并提供返回列表入口。
- 409（运行互斥）：提示先等待或停止当前运行。
- 网络中断：保留输入内容，提示后端不可达，允许重试。
- 模型未配置：阻止发送并提示所需环境变量名（不显示密钥值）。

**FR-G2 加载与空态**

- 所有数据加载有加载态；列表与面板有空态提示。
- 全局错误提示统一组件，不打断已加载数据展示。

## 6. 非功能需求

| 类别 | 需求 |
|---|---|
| 安全 | XSS 防护：Markdown 白名单渲染、动态内容转义、不执行原始 HTML；错误信息脱敏，不暴露密钥与供应商原始报错给终端展示（可展开的详情需脱敏） |
| 可靠性 | 后端重启 / 页面刷新后状态可恢复；SSE 断线可恢复最终状态；取消语义严格（无部分输出残留） |
| 性能 | 首屏加载常规 SPA 标准；消息流式渲染不阻塞输入区；长对话列表渲染不卡顿 |
| 兼容性 | 支持当前版本 Chrome 与 Edge，桌面端为主，不做移动端专门适配 |
| 数据 | SQLite 双库（业务库 + LangGraph checkpoint 库）；MVP 数据不迁移，正式项目从零开始 |
| 可观测 | LangSmith 默认关闭、可配置开启；日志不打印密钥 |

## 7. 与 MVP 原型的关系

| 维度 | MVP 原型 | 正式版 |
|---|---|---|
| 功能范围 | T001–T003 已实现，T004–T007 已定义 | 全部覆盖（含 T004–T007 的仪表盘、配图、素材、参数功能） |
| 后端 | FastAPI + LangGraph + SQLite | **契约不变迁移**，包结构统一，新增生产静态托管 |
| 前端 | 原生 HTML/CSS/ES Modules，无构建 | React 19 + Vite + TS + Ant Design 5 + TanStack Query + Zustand |
| 信息架构 | 5 页面 MPA + 侧边栏注入 | 同构 SPA 路由（见 4.2） |
| 数据 | `prototype/.../data/` | 独立 `data/` 目录，从零开始 |
| 部署 | 前后端分别启动 | 开发分离热更新；生产单进程（FastAPI 托管前端产物） |

MVP 原型目录冻结归档，不再开发；正式版功能行为以本 PRD 与 MVP 已验收语义为基线。

## 8. 明确不做的事情

- 登录、权限、多用户与团队协作。
- 大纲确认节点（保持"需求 → 必要时追问 → 直接生成"流程）。
- 正文直接编辑（正文只读，只能通过对话修改）。
- 版本恢复、版本对比、版本删除。
- RAG、联网搜索、知识库、多智能体、自动审稿。
- 文章删除、归档、标签、全文检索。
- 移动端适配。
- 云部署与水平扩展。
