# T020：配图方案快捷进入生图流程

## 1. 任务信息

- 状态：已完成（人工验收通过，2026-09-06）
- 优先级：P1
- 类型：配图工作台交互优化
- 前置任务：T004（配图工作台）、T015（配图计划模式）
- 后续任务：无
- 目标目录：`frontend/src/pages/`、`frontend/src/features/image-workspace/`、`frontend/src/styles/`
- 创建日期：2026-09-06
- 需求来源：配图方案生成后，需要复制提示词、切换行动模式并粘贴后才能生图，操作链路较长

## 2. 目标

当前会话已有配图方案时，在行动模式右侧结果区提供“当前图片 / 配图方案”切换，并允许将任一方案提示词直接带入生图输入区，减少手动复制、切换与粘贴操作。

## 3. 已确认决策

| 编号 | 决策 |
|---|---|
| D1 | “用于生图”只填入提示词，仍由用户检查后点击“发送”，不直接触发可能产生费用的生图请求 |
| D2 | 排版建议自动映射比例：横版 `16:9`、方图 `1:1`、竖版 `9:16`；分辨率档位保持当前值 |
| D3 | 输入框存在不同的未发送草稿时，先弹窗确认是否覆盖 |
| D4 | 点击“发送”后右栏自动回到“当前图片”；生成期间仍允许手动切回“配图方案” |
| D5 | 仅当前会话存在已保存或刚生成的方案时显示右栏结果切换；无方案时保持原“当前图片”界面 |

## 4. 实现记录

### 4.1 会话方案恢复与右栏切换

- `ImageWorkspacePage` 进入会话后即查询最近一次配图方案，不再限定只有计划模式才加载。
- 行动模式检测到方案后，在右栏标题区显示“当前图片 / 配图方案”切换。
- “配图方案”视图复用 `ImagePlanResults`；“当前图片”继续承载生成进度、图片预览和保存素材功能。

### 4.2 用于生图

- `ImagePlanResults` 增加可选的 `onUsePrompt` 回调和“用于生图”按钮，同时保留原“复制”按钮。
- 使用方案后自动进入行动模式、填充提示词并应用排版建议对应的图片比例。
- 当前提示词草稿非空且与目标方案不同时，通过确认弹窗保护未发送内容。
- 发送请求时自动切换到“当前图片”；结果切换控件不因运行状态禁用，用户可继续查看方案。
- 生图运行期间禁用方案卡片的“用于生图”，避免覆盖正在运行任务的输入状态。

### 4.3 样式与测试

- 增加方案卡片操作按钮组样式。
- 扩展 `ImageWorkspacePage.test.tsx`，覆盖：
  - 行动模式恢复并查看已有方案；
  - 提示词填充及横版、竖版比例映射；
  - 未发送草稿覆盖确认；
  - 发送参数正确；
  - 发送后自动展示当前图片；
  - 生成期间仍可切回配图方案。
